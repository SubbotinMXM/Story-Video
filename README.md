# Story Video

Приложение для Mac: текст рассказа → озвучка → готовый ролик с подобранным видеорядом.

- **Футажи** — озвучка + нарезка ваших футажей (8 кусков на ролик), голова диктора (всегда справа сверху),
  надпись (всегда слева сверху), интро/аутро.
- **Стоковые слайды** — озвучка → Whisper (тайминги, язык определяется сам) → тема от LLM →
  видео и фото с YouTube, Pexels, Pixabay, Unsplash, Google, Wikimedia, Archive (отбор нейросетью CLIP) → ролик 1080p.
- **Копии ролика** со сдвигом скорости (99%, 101%, …).

## Установка и запуск

Нужен **Mac с чипом M1/M2/M3/M4**, macOS 13+, интернет и ~8 ГБ свободного места.

```bash
git clone <ссылка на репозиторий> story-video
cd story-video
./run.sh
```

Или двойной клик по `Запуск.command`.
Если проект скачан ZIP-архивом (не `git clone`), macOS может не открыть `Запуск.command`
двойным кликом («неизвестный разработчик») — тогда правый клик → «Открыть» или запуск `./run.sh` из Терминала.

**Первый запуск сам ставит всё нужное** (10–20 минут, дальше приложение открывается сразу):

| Что | Зачем |
|---|---|
| Homebrew | менеджер программ macOS; установщик **один раз попросит пароль от Mac** |
| Python 3.14 | на нём работает приложение |
| ffmpeg-full | сборка видео и вшитые субтитры |
| библиотеки Python (`requirements.lock`) | ровно те версии, на которых всё проверено |
| Chromium | поиск картинок в Google/Bing |
| модели Whisper и CLIP (~1,4 ГБ) | распознавание речи и отбор кадров |

`./run.sh --setup-only` — только установить/проверить, не запуская. `./run.sh --browser` — открыть в браузере.
yt-dlp (скачивание с YouTube) обновляется сам раз в неделю: YouTube часто меняется.

## Ключи

Вписываются в приложении: **Настройки**. Хранятся только у вас в `data/config.json` (в git не попадают).

| Ключ | Для чего | Обязателен |
|---|---|---|
| Lumean API key + Voice ID **или** VoiceGen API key | озвучка (сервис выбирается в карточке «Озвучка») | да, если нет готового аудио |
| LLM API key (OpenAI-совместимый) | тема ролика и поисковые запросы | для стоковых слайдов |
| Pexels / Pixabay / Unsplash | стоковые видео и фото; можно по несколько ключей — на лимите берётся следующий | желательно |
| YouTube Data API (можно несколько) | видеонарезки с YouTube (только лицензия Creative Commons); ~100 поисков в сутки на ключ, кончилась квота — берётся следующий | желательно |

VoiceGen: голос, скорость и модель задаются в шаблонах в Telegram-боте VoiceGen.
Создали или поменяли шаблон в боте — нажмите **«Обновить»** у списка «Шаблон», и он появится в приложении.

**Ролики на других языках (только VoiceGen).** Отметьте языки в карточке «Озвучка». Ролик на языке текста
делается всегда; язык текста определяется сам, его галочка пропускается. VoiceGen переводит готовую озвучку,
подгоняя фразы под время оригинала, поэтому видеоряд берётся тот же — меняются голос и субтитры.
Каждый язык — отдельная папка на Рабочем столе: «Тема 14.10 (EN)». Стоимость языка в VoiceGen —
1,5 символа баланса за символ перевода; оригинал повторно не оплачивается.

## Как пользоваться

- Тексты можно добавлять в очередь в любой момент: **одновременно идут 2 ролика**, остальные ждут.
  Пока идёт работа, Mac не уходит в сон.
- Упал ролик (кончились деньги на ключе, нет сети) — поправьте настройки и нажмите
  **«Продолжить с места падения»**: готовое (в том числе оплаченная озвучка) не переделывается.
- **Ролик про конкретного человека** (LLM определяет по тексту): кадры только с ним. Для людей эпохи
  фотографии — его фото из Google/Wikimedia и видео YouTube (CC), проверка по лицу (OpenCV) отсекает
  здания и других людей; для древних (Цезарь) — его статуи, бюсты, картины. Действует во всех режимах.
- Режимы подбора кадров: **по смыслу ролика** (быстро) · **строго первые 2 минуты** (кадр под фразу каждые 3–5 с,
  фото и видео; дальше пул 80–100 фото + 10–15 видео по теме) · **строго весь ролик** (кадр под текст каждые 3–5 с).
  Фото стоят 3–5 с, видео — до 6 с. Видео — цель 1080p, не ниже 720p; одинаковые и почти одинаковые кадры
  (то же фото с другого сайта, тот же клип) в ролик попадают один раз и подряд не ставятся.
  Призыв подписаться в тексте получает не буквальный кадр, а видео по теме ролика.
- **Фоновая музыка** (стоковые слайды, необязательно): 20 треков в 5 группах, кнопка «Послушать».
  Трек играет по кругу на весь ролик, ровно и на ~20 дБ тише голоса. Треки — FreePD (общественное
  достояние CC0), без претензий YouTube; подготовлены `tools/prepare_music.py` (одна громкость, бесшовный стык).
- **Шаблоны** (необязательно): настройте страницу как нужно (интро/аутро, голова, субтитры, подписка, копии,
  озвучка) и нажмите «Сохранить как шаблон». Потом выбор шаблона в списке заполняет все поля разом.
  У футажей и слайдов шаблоны свои. Ключи API в шаблоны не попадают.
- Готовый ролик — в папке на Рабочем столе. Рядом `источники.txt`: авторы YouTube-нарезок
  (лицензия CC BY требует указать их в описании ролика).

## Устройство

```
desktop.py        сервер (FastAPI) + окно приложения (pywebview); одна копия на компьютер
server/           HTTP API: настройки, очередь (2 ролика сразу), события, диалоги файлов
engine/           пайплайны, без интерфейса
  core/           настройки, лог, Lumean, отмена, ограничители, расстановка без повторов
  tts/            сервисы озвучки: общий интерфейс + Lumean, VoiceGen
  slides/         стоковые слайды: Whisper, тема, источники, отбор, рендер
  broll/          футажи
  compositor/     ffmpeg-сборка футажей
web/              интерфейс: React + Vite + TypeScript; собранный — в web/dist (в git, Node не нужен)
tests/            unittest: python -m unittest discover -s tests -p '*.py'
data/             config.json, очередь, журнал, запуски — только локально
```

## Разработка

```bash
.venv/bin/python desktop.py --dev                      # API на :8765
cd web && npm install && npm run dev                   # интерфейс на :5173 с горячей перезагрузкой
.venv/bin/python -m unittest discover -s tests -p '*.py'
```

Перед коммитом правок интерфейса — `cd web && npm run build` (в git идёт web/dist).
Обновили библиотеки и тесты прошли — `.venv/bin/pip freeze > requirements.lock` (без строки yt-dlp).

### Новый сервис озвучки

1. `engine/tts/<сервис>.py`: класс-наследник `TtsProvider` (см. `engine/tts/lumean.py`):
   - `fields`: настройки (`secret`, `text`, `slider`, `named_list`, `remote_list` — список из кабинета
     сервиса с кнопкой «Обновить», заполняется методом `refresh`). Интерфейс рисует их сам,
     `quick=True` показывает поле в карточке «Озвучка» на странице ролика;
   - `synthesize(text, dest, opts, state_file=…)`: mp3 в `dest`. Если у сервиса есть заказы,
     сохраняйте id в `state_file`, чтобы «Продолжить» не оплачивало озвучку второй раз;
   - `ping(opts)`: проверка ключа.
2. Добавить экземпляр в `PROVIDERS` в `engine/tts/__init__.py`.
